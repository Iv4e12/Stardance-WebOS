Stardance WebOS: v1!

A custom, fedora inspired OS built from scratch for the Stardance Program. This project uses any web browser so you can experince a Linux Fedora based operating system.

Features
- So many windows... Spawn as many independent windows as you want!
- Interactive Terminal: A functional Konsole!
- Clock! A real-time clock.
- Wallpaper Engine: Switch between 4 different wallpapers by using the Switch Wallpapers app!

Konsole commands
Open the terminal and try these cmds:
- help - Lists all available commands.
- neofetch - Displays information about the "Operating system"
- sudo - Root access ;)
- exit - Closes the active terminal window
- clear - Wipe everything you've written in the terminal window
