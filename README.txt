# 🌌 Stardance WebOS: Workspace v1.0

A custom, Linux-inspired desktop environment built from scratch for the **Hack Club Stardance** challenge. This project uses vanilla web tech to simulate a Linux based operating system.

## 🛠️ Features
- **Dynamic Window Factory:** Spawn as many independent windows as you want!
- **Interactive Terminal:** A functional command line Konsole.
- **Custom Desktop Clock:** A real-time clock.
- **Wallpaper Engine:** Switch between 4 different desktop themes directly from the Launcher.
- **Glassmorphism UI:** Modern, translucent window designs inspired by KDE Plasma.

## 💻 Terminal Commands
Open the terminal from the Launcher and try these:
- `help` - Lists all system commands.
- `neofetch` - Displays OS and kernel information.
- `sudo` Root access ;)
- `exit` - Instantly terminate the active terminal window
- `clear` - Wipe the terminal logs.
